# OpsPilot — Project Context

## Project Overview

OpsPilot is a fictional AI-powered operations platform designed as a serious full-stack software engineering portfolio project.

The goal is to demonstrate production-oriented skills in:
- Full-stack development
- Software architecture
- AI engineering
- RAG
- Database engineering
- API development
- Authentication and authorization
- Testing
- DevOps
- CI/CD
- Cloud deployment
- Observability
- Security

## Product Concept

OpsPilot provides businesses with a centralized platform for managing:
- Customers
- Support tickets
- Orders
- Internal company knowledge
- Analytics
- AI-assisted operations
